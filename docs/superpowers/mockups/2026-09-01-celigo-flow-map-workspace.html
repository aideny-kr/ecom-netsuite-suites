🛡 Script source is treated as untrusted input. It is shown to you and quoted to the assistant inside a sealed block — never followed as instructions, never run. Nothing on this surface can edit or deploy it. 
function setAccount(options) {
  var sub = options.record.getValue('subsidiary');
  return SUBSIDIARY_ACCOUNTS[sub] || DEFAULT_DEPOSIT_ACCOUNT;
}

Why this surface has no Deploy button. The workspace’s Files surface can edit and deploy SuiteScript. These scripts belong to the customer’s own integrators, so the Celigo surface renders instead of that one — the deploy controls are never mounted, not merely hidden.
