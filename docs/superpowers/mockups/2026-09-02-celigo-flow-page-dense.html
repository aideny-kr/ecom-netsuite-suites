The bubble. Eyebrow = kind + app family. Title = Celigo's own export/import name once it is synced; until then the honest fallback is operation record_type for NetSuite steps and "HTTP export · name not synced" for the rest — never a made-up name. Fact line = adaptor · operation · record type (or saved search id for NetSuite exports). Then the four affordances in a fixed order — filter, hooks, transform, mapping — so an absent one is visible as a hollow chip, the way Celigo leaves the circle empty. A hook chip carries the function name and the script's clone state: ×6 means six identical copies; B/3 means this step runs copy B of a family with three differing versions, and the amber dot says so without a tooltip. Footer = the two per-step flags Celigo hides in a settings drawer (skip retries; proceed on failure, which also dashes the outgoing edge).

Layout is deterministic, never force-directed. Ranks left-to-right: sources · top-level chain · router · branch lanes; a branch stacks its steps in sequence order. Positions come from a tiny layered layout (no dagre in the repo; ~80 lines), so the same flow always draws the same way and a refetch never reshuffles it.

Navigation

  • One page, four URL params. /workspace?surface=celigo (tiles) · &integration= (flows table) · &flow= (full page) · &step= and &script= (selection, drawer). Every state is a link; refresh keeps it; Back walks up.
  • surface moves from React state into the URL — today it is a useState, so a refresh drops you back to Files.
  • Breadcrumb at every level; the navigator pane hops between sibling flows without going up. ⌘B collapses it like the Files explorer. ⌘K searches integrations and flows.
  • The Celigo branch of workspace/page.tsx mounts its own panel group (navigator · canvas · inspector). The Files group — file tree, changesets, diff viewer, Deploy — is never in the tree on this branch. That guarantee gets a page-level test.

What it takes · 13 days

  • Backend, T1, ~2.5 d — record_type/operation/search_id on steps · per-step error counts + flow errors route · integration summary (writes, stalled, scripts, changes) · router/branch projection from raw_json · changes route. Tests first.
  • Frontend, ~10 d — URL state (0.5) · tiles + list (1) · integration page + tabs (1) · flow page shell in the panel group + navigator (1) · canvas: layered layout, bubble, router, edges (2.5) · inspector tabs (1.5) · script drawer from the dialog (0.5) · stall heuristic + states (1) · tests + retire the old map (1).
  • Not included — names sync (~1.5 d, T2), connections (~2 d + live probe, T2), NetSuite field mapping (~1 d, T2), run history (~3 d, T2).
  • Tier: T2 gate for the PR (new endpoints over customer JavaScript and error payloads; workspace shell change).

Decisions to confirm

  1. Celigo's three levels, kept. Tiles → integration table → full-page flow. The alternative — tiles straight to flow with the table folded into the navigator — saves one click and loses the place where 20 flows are compared.
  2. Honest fallbacks over invented names. Until the T2 name sync, a bubble is titled by what it does (add salesorder) and says "name not synced". The toggle above shows both.
  3. Drawer for source, Scripts view for the family. Not a page jump from a bubble.
  4. N2 holds. Source in the drawer only, human-only, never in the inspector, never to the assistant. Search on this surface is plain text.
  5. No writes. No Run, no Off/On, no retry/resolve. "Open in Celigo ↗" is the one way out.

Risks

  • Stall detection is a heuristic on one cron shape. It must say "stalled?" with the question mark, use sync time not wall time, and go silent on any cron it does not parse.
  • Zero live errors means the error state ships unverified against real data — the fourth fixture-vs-live blind spot. Mitigation: replay the 17 Aug payload shape from the spec as the fixture, and mark the state "untested live" in the PR.
  • Multi-router chains (nextRouterId) draw wrong until the raw_json projection lands; the layout must fall back to a single-router rank, never crash.
  • reactflow on the workspace page — lazy-load the canvas so Files users never pay for it.
  • Panel-group ids collide with the Files group's persisted layout unless the Celigo group has its own id.
