The existing unified agent gains maintained skills, case-scoped reference research, evidence-backed treatment assessment and verified resolution history. It retains the existing application models, connectors, signed approval, scoped financial adapters, preflight, locks, idempotency and durable read-only outcome recovery.

## Work in progress

- On-demand skills: compact accounting core for transaction workflows; subledger, treatment and verification skills loaded through a read-only catalog tool. Skill revision is audited. Transaction prompts do not eagerly include Metabase analysis manuals; connected tools remain available and their skills can be loaded if needed.
- Research: authorized case plus fixed public product topic; bounded official Oracle search/reads. No customer parameters enter the search. Retain source URLs, retrieval time, content hash and whether a document or only a snippet was read. References cannot authorize a financial change.
- Assessment: existing scoped native evidence and adapter eligibility produce an explicit selected supported treatment, alternatives requiring evidence, unresolved facts, policy/configuration basis and verification requirements. Assessment and reference provenance accompany the signed proposal/audit. No generic fallback posting.
- Usage: expose persisted input/output/cache creation/cache reads through API and stream. Anthropic cache counts are additive; OpenAI input already includes cached input. Unknown historical cache remains unknown. UI reports usage rather than monetary cost.

## Remaining delivery

Connect verified chat accounting outcomes to scoped resolution examples, preserving original approver and complete native/reconciliation proof; historical success must never transfer authority or automatically become policy. Exercise realistic single/group investigations and failure recovery with actual tool plumbing. Address observed gaps rather than inventing universal accounting rules or treating all alternatives as executable.

Acceptance requires applicable financial/auth/tenant/approval/idempotency regression tests, realistic agent scenarios, seeded e2e, one independent review pinned to the release revision, CI, coherent staging deployment, safe UAT smoke and actual rendered browser verification. Live NetSuite writes require real in-app human approval. No production app deployment or PR merge is authorized by this work plan.
